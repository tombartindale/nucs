# Unit 1 — Activity

**What to do.** Take a subject you are interested in and write three versions
of it as an answerable question, each with a different scope.

**What you produce.** A single page, three questions, one sentence each on what
would count as an answer.

**How long.** About 40 minutes.

**How to tell you have done it well.** Each question names what would count as
an answer, and the three differ in scope rather than in wording.
